# actions.json.storage.public

Reviewed public artifacts promoted from `actions.json.storage`.

This repository is the public scope for artifacts that are safe to share broadly:
generalized reports, redacted action-map lessons, reusable examples, and public
documentation generated from private design work.

## Artifacts

- [Schema comparison report](docs/reports/schema-comparison.html)
- [Schema V1 teaching deck](docs/decks/schema-v1-proposal-deck.html)

## Policy

- Do not store raw browsing observations, private account state, secrets,
  cookies, tokens, payment data, or private screenshots.
- Promote artifacts here only after review and redaction.
- Keep public artifacts linkable from Linear, GitHub pull requests, and future
  actions.json.storage views.
